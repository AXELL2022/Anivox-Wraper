# MPV IPC, Discord, resume и фоновый плеер

Дата: 2026-10-19. Изменения выполнены прямо в main по указанию пользователя, без новой ветки. Новая версия/тег не создавались.

## Реализовано

- Уникальный локальный named pipe Windows / Unix socket для каждого MPV, постоянное чтение JSON IPC; наблюдаются pause, time-pos, duration, speed, paused-for-cache, eof-reached.
- Метаданные аниме/серии фиксируются при запуске. Готовый MPV имеет приоритет Discord; встроенный snapshot сохраняется для возврата после завершения или ошибки IPC. Таймер учитывает скорость, паузу и буферизацию.
- playback-history.json атомарно хранит позицию по ключу anime:episode:translation, без токенов и ссылок на потоки. Повторный запуск в MPV предлагает продолжить, начать сначала или отменить. Ранние/финальные позиции исключаются из предложения. История ограничена 1000 записями, очищается из локальных настроек.
- mirrorEmbedded выключен по умолчанию. После готовности MPV встроенный HTML video становится беззвучным, штатный метод сайта changeQuality выбирает минимальное доступное числовое качество. Пауза/буферизация/перемотка/скорость следуют реальному MPV. Исходные качество, предпочтение качества и звук восстанавливаются при завершении; плеер остаётся на паузе.
- Защищены смена серии во время async-переключения качества и замена MPV-сессии. Старый процесс не перезаписывает историю новой сессии той же серии. Перемотка назад после EOF снова разрешает проигрывание.
