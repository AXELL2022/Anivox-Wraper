# Anivox (GTK) — экспериментальная нативная версия для Linux

Оболочка на GTK4 + WebKitGTK 6.0 без Tauri. Логика MPV, Discord, настроек и
истории общая с Tauri-версией (`src-tauri/anivox-core`), скрипты сайта — те же
(`src-tauri/scripts`). Настройки (`settings.json`, `tray.json`) и сохранённые
позиции общие с Tauri-версией; сеанс окна хранится отдельно (`session-gtk.json`).

## Что умеет

- Навигация: назад, вперёд, обновить, домой; ссылки на чужие сайты открываются
  в системном браузере.
- Кнопка «MPV»: текущая серия во внешнем плеере, статус плеера на кнопке.
  Discord Rich Presence, продолжение с сохранённой позиции, зеркалирование
  встроенного плеера (`mirrorEmbedded`).
- Сеанс: размер и развёрнутость окна, последняя страница anivox.fun; восстановленная
  страница не запускает видео до клика или клавиши.
- Трей (StatusNotifierItem): «Открыть», «Сворачивать в трей», «Выход». Крестик
  скрывает окно в трей; выход — только из меню трея. Без панели с треем крестик
  закрывает приложение.
- Настройки (шестерёнка): страница при запуске, путь к MPV, зеркалирование,
  очистка сохранённых позиций.
- Проверка соединения (Wi‑Fi): скорость интернета против скорости видео с сайта.
- Экран загрузки и восстановления: через 25 с без ответа сайта — «Повторить
  загрузку», «На зеркало» (anivox.me), «На главную», «Продолжить ожидание».
- Shikimori поверх сайта: тот же тайтл, закрытие кнопкой, Escape или кликом по
  фону; в Discord — тип страницы Shikimori.
- Обновления: при новой версии в панели появляется кнопка с описанием изменений;
  она открывает страницу выпуска для ручного обновления пакета.
- Без лока 60 FPS на мониторах 120–240 Гц (NVIDIA): `src/vblank.rs` и
  `GSK_RENDERER=gl`.

## Сборка

```sh
cargo run --release            # запуск из исходников
cargo test                     # тесты
cd arch && makepkg -fi         # пакет anivox-gtk для Arch и установка
```

Нужны `gtk4`, `webkitgtk-6.0`, Rust; для внешнего плеера — `mpv`. Пакет
ставится рядом с Tauri-пакетом `anivox` без конфликтов файлов.
